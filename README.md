# Sabri Saadi — Creative Portfolio

A responsive dark portfolio website for graphic design and visual communication.

## Included sections
- Hero and portfolio introduction
- Filterable project-category cards: brand campaigns, vehicle branding, retail & POS, print & promotion, and brand applications
- Services/about section
- Contact call to action

## Publish with GitHub Pages
1. Open **Settings** in this repository.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. Wait for GitHub Pages to finish deploying. The expected URL is https://sabrisaadi07.github.io/Graphic-design-project/ .

## Before sharing widely
- Replace `hello@example.com` in `index.html` with Sabri's approved contact email.
- Replace the graphic placeholder tiles with approved original project images and real project descriptions. The current tiles are illustrative placeholders and are not presented as actual client work.
- Confirm Sabri approves publishing this portfolio publicly.

No framework or build step is required; this is a static HTML page.
